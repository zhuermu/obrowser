    Use an AWS profile for SSO and automatically refreshed credentials.
    Checking local AWS profiles…
    Profiles are read from ~/.aws/config and ~/.aws/credentials. For an IAM Identity Center (SSO) profile, "Sign in with SSO" opens your browser and refreshes the session — the app then renews credentials automatically until that session expires.
    Service account keys support local URL signing. User ADC needs service-account impersonation to preview and download files.
    Where do I find this key?
    Create it in the Cloud Console: IAM & Admin → Service Accounts → pick the account → Keys → Add key → Create new key → JSON. Only the file path is saved here; the private key stays in the file on disk.

    Required storage permissions
