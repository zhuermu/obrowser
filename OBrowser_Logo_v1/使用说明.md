# OBrowser Logo 升级提案 · 01

## 设计主张

**一个 O，一个对象。**

从产品最基本的关系出发：用户通过 OBrowser 访问、浏览和管理对象存储。品牌标记不需要同时画出云、下载、上传、浏览器和存储桶。

- 打开的 O：对应 OBrowser / Object，开口表达访问。
- 独立圆角方块：一个可访问的对象，也是唯一的识别点。
- 蓝色 + 紫色：延续旧图的色彩记忆，但改为两块纯色，去除渐变依赖。
- 单色仍成立：意义由轮廓承担，不依赖颜色、光影和文字细节。

本方案是待确认的原创设计提案，未做商标检索或商业独占性核验。当前仅交付设计文件，没有替换现有产品资产或发布到线上。

## 推荐使用

| 场景 | 文件 |
| --- | --- |
| 默认横版 Logo | `svg/obrowser-lockup-color.svg` |
| 单独品牌符号 | `svg/obrowser-mark.svg` |
| 黑白印刷、低色数环境 | `svg/obrowser-lockup-mono.svg`、`svg/obrowser-mark-mono.svg` |
| 深色背景 | `svg/obrowser-lockup-white.svg`、`svg/obrowser-mark-white.svg` |
| 上下组合 | `svg/obrowser-lockup-stacked.svg` |
| 应用入口、头像、启动器设计参考 | `svg/obrowser-app.svg` |
| 浏览器标签页 | `svg/obrowser-favicon.svg`、`favicon/favicon.ico` |
| 快速审阅 | `obrowser-review.png` |

`png/` 内为透明背景的 PNG 导出。标志、应用图标提供 256 / 512 / 1024 像素；字标组合提供 960 / 1920 像素宽版本。应用图标本身有蓝色底板，底板外圆角区域透明。

`favicon/` 包含 16 / 24 / 32 / 48 / 64 像素 PNG；ICO 内含 16 / 32 / 48 / 64 像素图层。微型图标经过独立尺寸适配，不是把大型应用图标直接缩至 16 像素。

应用图标属于通用视觉资产，不是已经构建好的 macOS `.icns`、Xcode Asset Catalog 或 Android 自适应图标包；正式上架时按对应平台的遮罩、安全区和资源规格导出。

## 品牌规格

- 主蓝：`#3558F5`
- 对象紫：`#7448F5`
- 墨色：`#12182B`
- 反白：`#FFFFFF`
- 正式名称大小写：`OBrowser`，与原图一致。

主标志绘制于 256 × 256 坐标系；圆心 (128, 128)，外半径 96，内半径 64；圆环厚度 32，端头为半径 16 的圆帽。对象方块为 48 × 48，圆角 10，左上角 (168, 40)。

外围最小安全距离建议为圆环厚度的 1/2，即主坐标系 16 单位。横版字标组合已有基础留白，但与其他控件并置时仍需外加安全距离。独立符号建议不小于 24 px；16 px 场景优先使用专用 favicon。横版组合建议不小于 144 px 宽，最终按实际屏幕检查。

不要拉伸、旋转对象块、改变 O 与方块的间距、添加投影描边或让彩色版直接落在低对比度背景上。深色背景优先使用反白版。

## 字体与编辑

字标基于本机已安装的 Avenir Next Demi Bold 排列，保留品牌名称 OBrowser。交付的正式字标 SVG 已全部转为路径，不包含外部字体引用，打开无需安装字体。未分发字体文件；如果后续要做可编辑文字版本，应自行确认所用字体授权。

SVG 主文件无位图、无滤镜、无外部网络引用，适合继续在矢量设计软件中编辑。审阅海报含嵌入的 SVG 图像和说明文字，不用作正式 Logo 主文件。

`source/export.cjs` 可用 Node.js + sharp 从 SVG 主文件重建 PNG、ICO 和审阅图。`source/outline_wordmark.py` 记录字标转曲来源；重建字标需要对应系统字体和 fontTools。`source/export-checks.json` 记录本次导出尺寸及透明通道检查，不代表商标审查或全部平台验收。
