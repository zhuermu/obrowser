# OBrowser - Multi-Cloud Object Storage Browser

OBrowser is a cross-platform desktop application for browsing and managing files across multiple cloud object storage services. Built with Electron, it provides a unified interface for AWS S3, Azure Blob Storage, Aliyun OSS, and PCG (ParallelCluster) storage.

## Key Features

- Browse buckets/containers and objects across multiple cloud providers
- Upload/download files with drag-and-drop support
- Create and manage folders
- Preview files (text, images, PDFs)
- Generate temporary signed URLs for file access
- Manage multiple storage accounts with connection profiles
- Cross-platform support (Windows, macOS, Linux)

## Target Users

Developers, DevOps engineers, and system administrators who need to manage files across different cloud storage providers from a single desktop application.
